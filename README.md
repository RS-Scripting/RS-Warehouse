# Centralized Warehouse Management for Modern Minecraft Servers

RS-Warehouse is a high-performance Paper plugin that replaces traditional chest storage with a centralized warehouse system.

Instead of managing hundreds of overflowing chests, players deposit items into a shared warehouse where everything is organized using categories and subcategories. The result is a cleaner, faster, and more scalable storage solution for servers of any size.

---

## Features

- 📦 Shared warehouse inventory
- 📂 Categories and subcategories
- 📥 One-click item deposits
- 📤 Simple item withdrawals
- 🆕 Automatic discovery of new materials
- 🛠️ Full in-game administration
- 💾 SQLite database
- 🚀 Optimized for Paper servers

---

## Requirements

- Paper 1.21+
- Java 21+
