# Permissions

This page documents every permission node used by RS-Warehouse.

| Permission          | Description                                                               | Default |
|---------------------|---------------------------------------------------------------------------|---------|
| `rswarehouse.admin` | Allows access to the RS-Warehouse Admin menu and administrative features. | OP      |

## Admin Permission

The `rswarehouse.admin` permission is required to access the RS-Warehouse Admin menu.
Players must also be **OP** to access the Admin menu.
The Admin menu provides access to administrative functions such as:

- Creating and managing categories
- Managing subcategories
- Managing warehouse items
- Creating Server Commands
- Creating Server Rules
- Reloading the plugin
- Viewing warehouse statistics

Regular players do not need the admin permission to use the normal warehouse features.
